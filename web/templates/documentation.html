Getting Started

Welcome to the IaaS Platform documentation. This guide will help you understand how to use the platform effectively.

Creating a Reservation

  1. Navigate to the Dashboard
  2. Fill in the reservation form with:
    • VM Password (for SSH access)
    • Number of VMs (1-5)
    • Duration (1 minute to 24 hours)
    • Optional: Software packages to pre-install
  3. Click "Create Reservation"
  4. Wait for allocation (usually <30 seconds)

Accessing Your VMs

Once your reservation is active, you can access each VM through the web terminal by clicking "Open Terminal" on the reservation details page.

SSH Access

You can also connect via SSH from your local machine: 

ssh username@127.0.0.1 -p PORT_NUMBER

Best Practices

  • Use strong passwords for your VMs
  • Monitor your reservation expiration time
  • Release resources when you're done to free up capacity
  • Pre-install common packages to save time
